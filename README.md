
# Sense of Pitch

**耳コピを、もっと直感的に。**

Sense of Pitchは、楽曲のコード進行を耳で聴き取り、その場で再現・検証するために開発したスマートフォン向けアプリです。

Unity（C#）を使用して個人開発しました。

## 開発背景

耳コピの練習中、聴き取ったコード進行をすぐに再生して確かめたいと感じることがありました。

そこで、音楽を聴きながら直感的にコードを操作し、試行錯誤できるツールを自作することにしました。

## 主な機能

- コード進行の作成・再生
- キー変更・移調
- テンポ変更・ループ再生
- コードの編集・並べ替え
- スマートフォンのタッチ操作に対応したUI

## 技術スタック

- **ゲームエンジン：** Unity
- **言語：** C#
- **開発環境：** macOS

## 開発で工夫したこと

### 直感的な操作性

耳コピ中に思考を中断せず操作できるよう、コードの選択・変更・再生を少ない操作で行えるUIを目指しました。

### 実機での検証

スマートフォンにビルドし、実際に音楽を聴きながら操作感を確認しました。

操作時の誤入力や再生時の違和感など、実際の使用を通じて見つかった問題を改善しました。

## 開発を通じて学んだこと

初めてUnityを使用した個人開発です。

自分自身の課題を出発点として、機能設計・UI実装・実機検証・改善まで一連の開発プロセスを経験しました。
